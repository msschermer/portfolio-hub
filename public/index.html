Meta State Validator

Inspects the metadata a public site publishes: page metadata, structured data, crawler directives, sitemaps, and llms.txt, with conflicts surfaced across sources.

Built with
Node, Express, cheerio
Runs as
On-demand inspection of one public URL and its supporting files
When it fails
Refuses private and internal targets on every redirect hop, caps fetches by time and size, and returns partial results when supporting files cannot be read

PageSpeed Monitor

Watches performance scores across a list of sites on a schedule and flags any that drop below threshold, so a regression gets noticed before a client reports it.

Built with
Node, Express, SQLite
Runs as
Scheduled scan every six hours, unattended
When it fails
Retries with backoff, records why each check failed, and shows the reason in the dashboard

Form to CRM Bridge

Delivers website form submissions into whichever CRM a business already uses. One shared core, with each platform reduced to a small adapter.

Built with
PHP, WordPress, three CRM APIs
Runs as
A plugin, firing on every form submission
When it fails
Never blocks the submission, keeps the payload so the lead is recoverable, and separates what to retry from what needs a person

Preflight

Paste any URL and get the pre-launch checklist run against the live page in seconds: certificates, redirects, crawlability, and the settings that quietly keep a site out of search.

Built with
Node, Express, cheerio
Runs as
On demand, no scheduling, nothing stored
When it fails
Refuses private and internal addresses on every redirect hop, times out slow targets, and reports partial results rather than failing the whole run

Running

WCAG Translator

Describe an accessibility problem the way a developer would, or paste a rule id or a whole scanner report, and it names the WCAG success criteria behind the finding along with the techniques for fixing it.

Built with
Node, Express, the official W3C WCAG data
Runs as
An API, answering on demand, rebuilt monthly as W3C republish
When it fails
Halts the build on an unexpected W3C structure rather than shipping an empty index, keeps serving the last good data if w3.org is unreachable, and labels weak matches as leads rather than answers
